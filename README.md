# FocusList Task Tracker

FocusList is a lightweight task-management application created with HTML, CSS, vanilla JavaScript, and Vite. It allows users to organize tasks through a responsive browser interface.

## Major Functionality

### 1. Task management

- Add new tasks
- Edit existing tasks
- Mark tasks as completed or active
- Delete individual tasks

### 2. Task organization

- View all tasks
- Filter active tasks
- Filter completed tasks
- Search tasks by title
- Display the number of remaining tasks
- Clear all completed tasks

### 3. Persistent storage

- Save tasks in browser local storage
- Restore tasks after refreshing or reopening the application
- Preserve task titles and completion status

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Vite
- Git and GitHub

## Open-Source Reference

This project uses **TodoMVC** as an open-source functional and scope reference.

- TodoMVC repository: https://github.com/tastejs/todomvc
- TodoMVC application specification: https://github.com/tastejs/todomvc/blob/master/app-spec.md

TodoMVC demonstrates the expected behavior of a small task-management application, including creating, editing, completing, deleting, filtering, and saving tasks.

FocusList is an original implementation. Its HTML, CSS, JavaScript, interface design, project structure, and storage logic were written independently rather than copied from TodoMVC.
